# 流派差异说明

不同排盘传统在以下几处规则上做法不一。界面中受这些规则影响的结果旁边会显示一个 **!**，可以在八字页的「流派设置」中切换，设置保存在浏览器本地。代码见 `src/lib/schools.ts`。

## 出处可信度

| 等级 | 含义 |
|---|---|
| **A 已核实** | 读过实现源码，或者找到了原文或可靠的引述 |
| **B 通行说法** | 命理界广泛流传的口诀或规则，但没能核对古籍原文 |
| **C 待核实** | 根据一般认知整理，出处说法本身就有分歧，建议对照原书 |

## 1. 晚子时日柱 — A

23:00–24:00 出生时日柱算哪一天。两种算法都来自 tyme4ts 的实现，源码在 `tyme4ts/lib/index.ts` 中：

- **日柱算当天**（默认）：`LunarSect2EightCharProvider`，日柱取农历当天的干支，只有时柱进入子时。
- **日柱算次日**：`DefaultEightCharProvider`，子时一到就换日。

## 2. 起运算法 — A

都以「三天折一年、一天折四个月、一个时辰折十天」为原则，差别在精度和取整。四种算法均为 tyme4ts 自带：

| 选项 | 实现类 | 算法 |
|---|---|---|
| 精确到分钟（默认） | `DefaultChildLimitProvider` | 出生到节气的秒数，按 259200 秒 = 1 年逐级折算 |
| 按天数和时辰差 | `LunarSect1ChildLimitProvider` | 天数差 × 4 个月 + 时辰差 × 10 天 |
| 按分钟数取整 | `LunarSect2ChildLimitProvider` | 4320 分钟 = 1 年，360 分钟 = 1 个月，12 分钟 = 1 天 |
| 元亨利贞 | `China95ChildLimitProvider` | 同上，但只精确到天（对应「元亨利贞」排盘软件的做法） |

## 3. 天乙贵人 — B

两个口诀版本的区别只在**庚日**：

- **甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎**（默认）：庚取丑未，辛取寅午。一个整理古文的网站给出的表就是这个版本（「庚日醜未，辛日寅午」）[^1]，六壬类软件也用这个版本[^2]。
- **甲戊兼牛羊 … 庚辛逢马虎**：庚、辛都取寅午。另有资料把这句列在「阴贵神歌」中（检索结果里无法确定是哪一篇，仅供参考）。

这两个版本分别属于《渊海子平》和《三命通会》的说法流传很广，但本次检索没有找到两书原文来确认，所以算 B 级。

## 4. 阴干羊刃 — B/C

阳干羊刃取禄前一位（甲卯、丙午、戊午、庚酉、壬子），各家没有分歧。阴干有三种说法：

- **顺排**（默认）：乙辰、丁未、己未、辛戌、癸丑，即禄后一位。多数现代排盘软件采用。（C）
- **逆排**：乙寅、丁巳、己巳、辛申、癸亥，阴干逆行。（C）
- **阴干无刃**：有文章指出《三命通会》只论阳刃，认为阴干有刃是后人的误读[^3]。（B）

## 5. 贵人类神煞查法 — C

天乙、太极、文昌、国印这几种贵人，有的用日干和年干一起查，有的只用日干。所谓「古法以年为主，子平今法以日为主」是一般说法。用日干查到的结果在各家都算数，只有用年干查到的会标 **!**。

## 6. 三合类神煞查法 — C

驿马、桃花、华盖、将星、劫煞、亡神、灾煞按三合局起，基准可以是年支、日支，或两者都看（默认两者都看）。另外，基准柱自己不会被标记，比如子年生，年柱不会因为是子就标「将星」。

## 7. 午未合化 — C

六合歌诀通常作「午未合土」（默认）；也有人认为午未同属南方火地，应化火，或者认为不化。

## 未列入设置、但同样存在分歧的地方

- **魁罡**：本项目取庚辰、庚戌、壬辰、戊戌四日，也有资料把壬戌算进去。
- **红艳煞、孤鸾煞、十恶大败、阴差阳错**：各家列出的日柱略有出入，本项目采用最常见的列表。
- **真太阳时**：均时差用近似公式，误差约 ±1 分钟；不处理 1986–1991 年中国实行的夏令时。
